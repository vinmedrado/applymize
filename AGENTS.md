# Instruções permanentes do repositório

Antes de trabalhar no Applymize, leia integralmente:

1. `docs/CADERNO_DO_PROJETO.md`
2. `README.md`

O caderno é a fonte principal de memória sobre objetivo, arquitetura, decisões, mudanças recentes, limitações e validações do projeto.

Após qualquer mudança material:

- atualize a seção correspondente do caderno;
- registre a data e o commit, quando houver;
- atualize o README somente quando a mudança afetar a apresentação pública;
- preserve alterações e arquivos do usuário;
- não adicione `docs/prints-sistema/` a commits sem pedido explícito.

Contexto central: o Applymize é um portfólio full-stack e uma ferramenta de uso pessoal. Não presuma objetivo de SaaS comercial ou exposição pública do backend.
